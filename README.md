# Machben - Sistema de Controle de Validade 📦⏳

O **Machben** é um sistema web desenvolvido para a gestão de estoque e controle rigoroso da validade de produtos. O objetivo principal é evitar perdas financeiras e otimizar o processo de reposição (frios, congelados e secos). 

O grande diferencial deste projeto é a automação de notificações: o sistema é integrado a um Bot do Telegram que envia alertas diretos ao responsável sempre que um produto está próximo do vencimento.

## 🚀 Funcionalidades
- Cadastro e gerenciamento de produtos no banco de dados.
- Controle e cálculo automático de dias restantes para o vencimento.
- **Alertas Automatizados:** Integração via API para envio de mensagens automáticas para o Telegram.
- Interface responsiva e de fácil navegação.

## 🛠️ Tecnologias Utilizadas
- **Back-end:** PHP puro ("na unha")
- **Banco de Dados:** MySQL
- **Front-end:** HTML5, CSS3
- **Integração:** API do Telegram (Bot)
- **Infraestrutura:** Hospedado em servidor Hostinger
